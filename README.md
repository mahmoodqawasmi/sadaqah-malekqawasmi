# صدقة جارية على روح الشهيد مالك نضال القواسمي

موقع عربي بسيط للدعاء وقراءة سورة الفاتحة على روح الشهيد مالك نضال القواسمي، رحمه الله.

## رابط الموقع
https://mahmoodqawasmi.github.io/sadaqah-malekqawasmi/

## الملفات
- `index.html` — صفحة الموقع والتصميم والتفاعلات.
- `malek.png` — الصورة المستخدمة في الصفحة.

## النشر
الموقع منشور عبر GitHub Pages من الفرع `main`. التعديلات على الملفات تُنشر تلقائيًا بعد نجاح عملية البناء والنشر في تبويب **Actions**.

## ملاحظات تقنية
- الموقع يستخدم Tailwind CSS وLucide وخطوط Google Fonts من شبكات خارجية؛ قد تظهر الصفحة بتنسيق أبسط إذا تعذر الاتصال بها.
- عدّاد الدعوات والزيارات يعتمد على خدمة عدّ خارجية، ولذلك يعتمد عمله على توفر تلك الخدمة.
- عدّاد الفاتحة محفوظ محليًا في متصفح كل زائر، ولا يمثل إجماليًا مشتركًا بين الزوار.
